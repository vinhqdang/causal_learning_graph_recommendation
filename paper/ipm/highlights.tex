\section*{Highlights}
\begin{itemize}
\item Debiased graph propagation is biased beyond one hop: walks repeat edges.
\item DRUP removes this bias exactly for any odd number of hops.
\item Guarantees need nuisances independent of the log, e.g. a sample split.
\item The correction fixes score values but not rankings on four benchmarks.
\item Thinning audits show exposure invariance only for DR-edge configurations.
\end{itemize}
